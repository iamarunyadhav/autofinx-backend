# Coding rules

Preserve module boundaries and workspace authorization. Do not read credentials or raw metadata into research prompts. Keep source content inert; escape exported HTML and never enable remote PDF resources.

Use existing indicator and forecast code. Add meaningful tests for ownership, queue deduplication, budgets, unsafe documents, worker failures and chronological replay. Run php artisan test, frontend npm run build and npx eslint . before handoff.

Do not apply production migrations or change Supervisor/cron without authorized server access. Exact installation steps and open limitations belong in docs/NEXUS_OPERATIONS.md.
