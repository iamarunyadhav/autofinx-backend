# Decisions

- Keep the module in the existing Laravel/React applications.
- Reuse the scheduler and isolate workers; do not create another scheduler owner.
- Use typed Nexus artifacts rather than creating twenty nearly identical tables.
- Store runtime knowledge in storage, never mutate Git from scheduled workers.
- Global cost reservations protect a shared provider account; observations and approvals remain workspace-scoped.
- Preserve operator rejection/approval during repeated discovery.
- Forecast experiments are proxies and cannot validate a proposed strategy automatically.
