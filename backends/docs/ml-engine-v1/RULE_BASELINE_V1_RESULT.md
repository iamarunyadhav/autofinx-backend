## What was tested and what was not

Tested: exactly the pre-registered primary rule set x 3 live presets x 4 live coins (+ XRP / SUI), 3 ablations, 2 report-only sensitivities, matched random-side null with 100 seeds, costs 0.12 / 0.14 / 0.11 / 0.08, per year, per coin, day-block bootstrap, BH-FDR in two families of 18.
Not tested: other indicator parameters or fractal widths, other RR, other floor / cap (a fixed cap penalises SOL / SUI whose swings are wider: 19 % of SOL 15m signals pass), trailing / break-even, leverage / liquidation, real 1 s stop polling, maker fill rates, volatility / regime gates, stake sizing, expiries other than the three presets, the 2026 holdout (sealed). A FAIL here says: this specific rule under these costs and this data window showed no edge; it does not prove no trend-breakout edge exists anywhere.

## Interpretation for Quick Trade

Together with D-046 (no directional ML edge), D-047 (regime / tradeability rules, no after-cost edge), D-048 (exits / gates add no edge to a random direction) and D-049 (calibrated model probability, no profit), this adds one more independent family (trend-breakout with structure stop) with zero after-cost edge at the presets of 30-60 minutes. The common cause is the 0.12 % round trip against typical 30-60 minute moves of the order of 0.3-1 %. The only validated finding remains volatility information (D-050 frozen decisions), usable for risk control, not for direction. Nothing here supports a PAPER forward test of this rule.
